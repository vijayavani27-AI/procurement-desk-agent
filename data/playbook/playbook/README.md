# Acme Corp — Procurement Negotiation Playbook

The only source of Acme's negotiation rules. Read `policies/decision-procedure.md` first.

- `policies/` — rules for every negotiation
- `categories/` — one page per spend category
- `suppliers/` — one page per supplier: status and any contract terms
- `amendments/` — dated changes to category values
- `precedents/` — past decisions showing how Acme evaluates unusual offers

All prices are INR, excluding GST, per the category's normalized unit.
