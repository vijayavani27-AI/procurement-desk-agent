# Data source

All files in this folder are the official competition files of
**The Procurement Desk** (Data Sprint 2.0 by Anveshan, NIE Mysuru), downloaded unchanged from
https://www.kaggle.com/competitions/the-procurement-desk/data — licensed **CC BY-SA 4.0**.

They are included only so that `python agent.py --data data` reproduces `submission.csv` without any extra download.
No outside data is used.
